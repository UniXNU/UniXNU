# SweetHIDALS

Sensor DSP support for the Xiaomi Mi 10 (umi, SM8250): SLPI firmware boot via TrustZone, SMEM/SMP2P/GLINK, QRTR and the service locator, the FastRPC config server and a SEE ambient light client, exposed to iOS as an Apple ALS HID service.

| Repository | Maintainer | Scope |
| --- | --- | --- |
| [ios-umi](https://github.com/qcom-toolbox/ios-umi) | [qcom-toolbox](https://github.com/qcom-toolbox) | [XNU patches 0208–0214](https://github.com/qcom-toolbox/ios-umi/tree/main/xnu/patches) |

## State

Auto-brightness works from the ambient light sensor. No colour data (True Tone) and no motion sensors. Device page: [Xiaomi Mi 10 — iOS 16](/devices/umi-qcom-toolbox).

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the driver and its state; it does not take over maintenance.
