# unixnu-nativemobiledisplay

CPU software display, framebuffer copying and presentation for the Samsung Galaxy Tab S7 FE Wi-Fi (SM-T733).

## State

The CPU and GPU scanout paths work. The GOP scanout has no vblank interrupt; `vsync` supplies a timer.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the driver and its state; it does not take over maintenance.
