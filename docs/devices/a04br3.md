# Benesse TAB-A04-BR3 (a04br3)

a04br3 is the Benesse TAB-A04-BR3 tablet with the MediaTek MT8167 SoC, four Cortex-A35 cores, GIC-400, 2 GiB DRAM and eMMC. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | Contents |
| --- | --- | --- |
| [UniXNU-a04br3](https://github.com/mouseos/UniXNU-a04br3) | [mouseos](https://github.com/mouseos) | Board file, kernel config, ADT generator, GPT layout and bring-up scripts |
| [uefi-a04br3](https://github.com/mouseos/uefi-a04br3) | [mouseos](https://github.com/mouseos) | Mu-Silicium firmware with `MT8167Pkg` and `a04br3Pkg` |
| [NativeMsdc](https://github.com/mouseos/NativeMsdc) | [mouseos](https://github.com/mouseos) | MT8167 MSDC eMMC block driver |

## State

| Area | State |
| --- | --- |
| Board, kernel config, ADT and GPT | prepared |
| Firmware | `uefi-a04br3` builds from the Mu-Silicium tree |
| eMMC | NativeMsdc drives MSDC0; root and persistent modes are implemented behind boot arguments |
| Root authentication | owner root chain, signed root policies and the verified block path are wired |
| Hardware run | no UniXNU boot is documented yet |
| Unattended tests | watchdog reset into LK fastboot, `a04br3-autoreset` and UART screenshots are prepared |

The port needs base changes that are not upstream yet: an NS16550 console, a board init hook, the MSDC personality and MediaTek image headers. The repository uses the `mouseos/UniXNU` fork until those changes are merged.

## Maintenance

The maintainer owns the repositories and their release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.
