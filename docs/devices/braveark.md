# Brave Ark tablet (braveark)

Brave Ark tablet (braveark) is a SM8635 device. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [UniXNU-braveark](https://github.com/tattwamashi/UniXNU-braveark) | [tattwamashi](https://github.com/tattwamashi) |

## State

UEFI, the UniXNU menu, the payload, DarwinBoot and XNU BSD init on all 8 CPUs work. The iPadOS root image is in progress.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.
