# Xiaomi MIX 2 (chiron)

Xiaomi MIX 2 (chiron) is a SDM835 device. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [ios-party](https://github.com/to-mid/ios-party) | [to-mid](https://github.com/to-mid) |

## State

A minimal 4 KiB XNU and its own PID 1 heartbeat ran on hardware. Full iOS userland and the storage path are not yet available.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.
