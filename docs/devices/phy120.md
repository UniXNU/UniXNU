# OPPO Find X7 Ultra (PHY120)

PHY120 is the OPPO Find X7 Ultra with the SM8650 SoC. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [UniXNU-PHY120](https://github.com/peiyuesheng666/UniXNU-PHY120) | [peiyuesheng666](https://github.com/peiyuesheng666) | Boot manager menu works; payload and XNU pending |

## State

| Area | State |
| --- | --- |
| UEFI firmware and menu | works; 1440x3168 panel |
| Payload volume | not discovered |
| Vendor DXE stack | stops at `EnvDxeEnhanced`, `SmemDxe`, `DALSYSDxe` or `RamManagerDxe` |
| `kernel.macho` | not built; needs macOS and Xcode |
| userdata geometry | `first_lba` measured; `last_lba` still 0 |
| defconfig | derived from sheng; PHY120 values pending |

The repository records the boot image layout, the UEFI load address, the device tree extracted from `vendor_boot.img`, and the DXE extraction path.

## Build

```sh
git clone https://github.com/peiyuesheng666/UniXNU-PHY120
cd UniXNU-PHY120
./setup.sh /path/to/PHY120domestic_11_16.0.7.200CN01_*/IMAGES/uefi.elf
```

`setup.sh` clones the firmware tree, imports the phone's own DXE drivers from `uefi.elf`, builds the firmware and packs the boot images. Vendor binaries are regenerated from the user's firmware image and are not stored in the repository.

The device has `fastboot` disabled. The repository records the EDL partition table.
