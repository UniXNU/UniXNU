# Nubia RedMagic 8 Pro / 8 Pro+ (nx729j)

nx729j is the Nubia RedMagic 8 Pro and 8 Pro+ with the SM8550 SoC. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [UniXNU-nx729j](https://github.com/2713385115/UniXNU-nx729j) | [2713385115](https://github.com/2713385115) | Board files ported from sheng; runtime state not documented |

## State

The repository is derived from UniXNU-sheng and keeps the same iPad7,1 iPadOS 17.7.11 target. The board file records the userdata geometry from the stock fastboot package and the device GPT, and configures the SM8550 kernel archives.

The README is the sheng template and does not document a runtime state. Check the repository for the current panel, touch and bring-up values.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.
