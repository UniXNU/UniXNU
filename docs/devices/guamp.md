# Motorola Moto G9 Play (guamp)

Motorola Moto G9 Play (guamp) is a SM6115 device. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [UniXNU-guamp](https://github.com/itsChris122/UniXNU-guamp) | [itsChris122](https://github.com/itsChris122) |

## State

The Mu-Silicium firmware boots with fastboot and shows the UniXNU menu. The kernel has not been built.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.
