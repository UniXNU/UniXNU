# OnePlus 8T (kebab)

OnePlus 8T (kebab) is a SM8250 device. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [UniXNU-kebab](https://github.com/GFander/UniXNU-kebab) | [GFander](https://github.com/GFander) |

## State

The first milestone produces kernel.macho with the minimal device-tree platform. A bootable image is not prepared.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.
