# Motorola Moto Z2 Force (nash)

Motorola Moto Z2 Force (nash) is a MSM8998 device. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [UniXNU-nash](https://github.com/fcxuhaq3/UniXNU-nash) | [fcxuhaq3](https://github.com/fcxuhaq3) |

## State

UEFI, UniXNU and the payload passed on hardware. The repository and ADT are a skeleton; the 4 KiB XNU stage needs macOS or the GitHub runner.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.
