# OnePlus 6 (enchilada)

OnePlus 6 (enchilada) is a SDM845 device. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [UniXNU-enchilada](https://github.com/keyfan/UniXNU-enchilada) | [keyfan](https://github.com/keyfan) |

## State

The repository holds the board file, kernel configuration and device scripts. It does not document a hardware result.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.
