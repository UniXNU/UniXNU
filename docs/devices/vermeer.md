# Redmi K70 (vermeer)

vermeer is the Redmi K70 with the SM8550 SoC. The repositories below are independent community ports. The UniXNU organization does not maintain them.

| Repository | Maintainer | State |
| --- | --- | --- |
| [UniXNU-vermeer](https://github.com/mansar1337/UniXNU-vermeer) | [mansar1337](https://github.com/mansar1337) | Source XNU build baseline |
| [UniXNU-vermeer](https://github.com/yyx2025/UniXNU-vermeer) | [yyx2025](https://github.com/yyx2025) | Device repository ported from sheng; status not documented |

## State

The `mansar1337` repository records a source XNU build baseline. Compilation, final linking and artifact collection passed on GitHub Actions. The artifact is format-checked and is not a phone boot image. The `yyx2025` repository is a sheng-derived device repository with no documented runtime state.

## Maintenance

The maintainers own their repositories and their release decisions. UniXNU documentation lists the ports and their state; it does not take over maintenance.
