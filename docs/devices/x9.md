# OPPO Find X9 (x9)

OPPO Find X9 (x9) is a MT6993 device. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [unixnu_x9](https://github.com/tosasitill/unixnu_x9) | [tosasitill](https://github.com/tosasitill) |

## State

LK decompresses the kernel and applies the DTB overlay, then the phone hits HWT. UEFI is not reached; the repository estimates 25 to 30 percent.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.
