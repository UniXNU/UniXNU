# Microsoft Lumia 950

Microsoft Lumia 950 is a MSM8992 device. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [UniXNU-lumia950](https://github.com/ManGuy-Legend/UniXNU-lumia950) | [ManGuy-Legend](https://github.com/ManGuy-Legend) |

## State

The port uses the phone own UEFI, the UniXNU menu and DarwinBoot. No boot is documented.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.
