# OnePlus 15T (fairlady)

OnePlus 15T (fairlady) is a SM8850 device. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [UniXNU-fairlady](https://github.com/Osilvfe/UniXNU-fairlady) | [Osilvfe](https://github.com/Osilvfe) |

## State

The port has early UEFI, ADT and S1 to S6 screen diagnostics. No hardware result is documented.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.
