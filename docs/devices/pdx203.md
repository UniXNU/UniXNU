# Sony Xperia 1 II (pdx203)

Sony Xperia 1 II (pdx203) is a SM8250 device. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [UniXNU-pdx203](https://github.com/chardidathing/UniXNU-pdx203) | [chardidathing](https://github.com/chardidathing) |

## State

The kernel builds and prelinks in CI, including the NativeUfs, NativeAES and PMGR archives. Nothing has booted on the phone.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.
