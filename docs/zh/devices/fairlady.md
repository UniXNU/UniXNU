# 一加 15T（fairlady）

一加 15T（fairlady） 是搭载 SM8850 的设备。下面的移植是独立的社区项目，UniXNU 组织不维护它。

| 仓库 | 维护者 | 状态 |
| --- | --- | --- |
| [UniXNU-fairlady](https://github.com/Osilvfe/UniXNU-fairlady) | [Osilvfe](https://github.com/Osilvfe) |

## 状态

移植包含早期 UEFI、ADT 和 S1 到 S6 屏幕诊断。未记录真机结果。

## 维护

维护者拥有仓库和发布决定。UniXNU 文档记录移植及其状态，不接管维护。
