# Redmi K30 5G（picasso）

picasso 是搭载 SM7250 的 Redmi K30 5G。下面的移植是独立的社区项目，UniXNU 组织不维护它。

| 仓库 | 维护者 | 状态 |
| --- | --- | --- |
| [UniXNU-picasso](https://github.com/YinCQL/UniXNU-picasso) | [YinCQL](https://github.com/YinCQL) | 早期骨架，固件未构建 |

## 状态

仓库包含板级描述、内核 defconfig、ADT 生成器和 package 钩子。固件构建尚未通过。内核、IPSW 和 userdata 章节是 bring-up 期间要填写的占位值。仓库说明可能出现故障。

## 维护

维护者拥有仓库和发布决定。UniXNU 文档记录移植及其状态，不接管维护。
