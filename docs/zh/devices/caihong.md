# 一加平板 Pro（caihong）

一加平板 Pro（caihong） 是搭载 SM8650 的设备。下面的移植是独立的社区项目，UniXNU 组织不维护它。

| 仓库 | 维护者 | 状态 |
| --- | --- | --- |
| [UniXNU-caihong](https://github.com/Axiang-dev/UniXNU-caihong) | [Axiang-dev](https://github.com/Axiang-dev) |

## 状态

板级文件和第一阶段 defconfig 可解析。把 UniXNU 接入 UEFI 树的工作尚未完成。

## 维护

维护者拥有仓库和发布决定。UniXNU 文档记录移植及其状态，不接管维护。
