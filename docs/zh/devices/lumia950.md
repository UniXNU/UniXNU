# Microsoft Lumia 950

Microsoft Lumia 950 是搭载 MSM8992 的设备。下面的移植是独立的社区项目，UniXNU 组织不维护它。

| 仓库 | 维护者 | 状态 |
| --- | --- | --- |
| [UniXNU-lumia950](https://github.com/ManGuy-Legend/UniXNU-lumia950) | [ManGuy-Legend](https://github.com/ManGuy-Legend) |

## 状态

移植使用手机自带 UEFI、UniXNU 菜单和 DarwinBoot。未记录启动。

## 维护

维护者拥有仓库和发布决定。UniXNU 文档记录移植及其状态，不接管维护。
