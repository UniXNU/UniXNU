# 摩托罗拉 Moto G9 Play（guamp）

摩托罗拉 Moto G9 Play（guamp） 是搭载 SM6115 的设备。下面的移植是独立的社区项目，UniXNU 组织不维护它。

| 仓库 | 维护者 | 状态 |
| --- | --- | --- |
| [UniXNU-guamp](https://github.com/itsChris122/UniXNU-guamp) | [itsChris122](https://github.com/itsChris122) |

## 状态

Mu-Silicium 固件可用 fastboot 启动并显示 UniXNU 菜单。内核尚未构建。

## 维护

维护者拥有仓库和发布决定。UniXNU 文档记录移植及其状态，不接管维护。
