# OPPO Find X7 Ultra（PHY120）

PHY120 是搭载 SM8650 的 OPPO Find X7 Ultra。下面的移植是独立的社区项目，UniXNU 组织不维护它。

| 仓库 | 维护者 | 状态 |
| --- | --- | --- |
| [UniXNU-PHY120](https://github.com/peiyuesheng666/UniXNU-PHY120) | [peiyuesheng666](https://github.com/peiyuesheng666) | 启动管理器菜单工作，负载和 XNU 待完成 |

## 状态

| 区域 | 状态 |
| --- | --- |
| UEFI 固件和菜单 | 工作，1440x3168 面板 |
| 负载卷 | 未被发现 |
| 厂商 DXE 栈 | 停在 `EnvDxeEnhanced`、`SmemDxe`、`DALSYSDxe` 或 `RamManagerDxe` |
| `kernel.macho` | 未构建，需要 macOS 和 Xcode |
| userdata 几何 | 已测 `first_lba`，`last_lba` 仍为 0 |
| defconfig | 从 sheng 派生，PHY120 数值待补 |

仓库记录了启动镜像布局、UEFI 加载地址、从 `vendor_boot.img` 提取的设备树，以及 DXE 提取路径。

## 构建

```sh
git clone https://github.com/peiyuesheng666/UniXNU-PHY120
cd UniXNU-PHY120
./setup.sh /path/to/PHY120domestic_11_16.0.7.200CN01_*/IMAGES/uefi.elf
```

`setup.sh` 克隆固件树，从 `uefi.elf` 导入手机自己的 DXE 驱动，构建固件并打包启动镜像。厂商二进制从用户自己的固件镜像重新生成，不存放在仓库中。

设备的 `fastboot` 已禁用，仓库记录了 EDL 分区表。
