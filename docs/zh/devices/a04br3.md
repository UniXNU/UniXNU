# Benesse TAB-A04-BR3（a04br3）

a04br3 是搭载联发科 MT8167 的 Benesse TAB-A04-BR3 平板，四核 Cortex-A35、GIC-400、2 GiB DRAM 和 eMMC。下面的移植是独立的社区项目，UniXNU 组织不维护它。

| 仓库 | 维护者 | 内容 |
| --- | --- | --- |
| [UniXNU-a04br3](https://github.com/mouseos/UniXNU-a04br3) | [mouseos](https://github.com/mouseos) | 板级文件、内核配置、ADT 生成器、GPT 布局和 bring-up 脚本 |
| [uefi-a04br3](https://github.com/mouseos/uefi-a04br3) | [mouseos](https://github.com/mouseos) | 带 `MT8167Pkg` 和 `a04br3Pkg` 的 Mu-Silicium 固件 |
| [NativeMsdc](https://github.com/mouseos/NativeMsdc) | [mouseos](https://github.com/mouseos) | MT8167 MSDC eMMC 块驱动 |

## 状态

| 区域 | 状态 |
| --- | --- |
| 板级、内核配置、ADT 和 GPT | 已准备 |
| 固件 | `uefi-a04br3` 可从 Mu-Silicium 树构建 |
| eMMC | NativeMsdc 驱动 MSDC0；root 和持久模式通过启动参数启用 |
| 根认证 | owner root 链、签名根策略和 verified block 路径已接通 |
| 真机运行 | 尚未记录 UniXNU 启动 |
| 无人值守测试 | watchdog 复位到 LK fastboot、`a04br3-autoreset` 和 UART 截图已准备 |

这个移植需要尚未上游的基础改动：NS16550 控制台、board init 钩子、MSDC 驱动和 MediaTek 镜像头。改动合并前，仓库使用 `mouseos/UniXNU` 分支。

## 维护

维护者拥有仓库和发布决定。UniXNU 文档记录移植及其状态，不接管维护。
